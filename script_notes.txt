Slides 3 - 10: Algorithm Explained

~2m, Finney

Slide 3

Arithmetic coding works by representing an entire message as a number within a progressively smaller interval. We start with the interval between zero and one. We encode the message one character at a time. In this case, we are using the example DAD.

Slide 4

We divide the interval according to the probabillity of each symbol. Now here, D has a probabillity of 2/3, and A has a probabillity of 1/3. As you can see, each symbol is assigned a coresponding proportion of the available interval.

Slide 5

The first character is D, so we keep the D section and we discard the rest. The intarval is now zero to 2/3. This is the first reduction in the range of possible values that could represent the original message.

Slides 6–7

We can now divide the smaller interval using the same probabillities as before. Our next character is A, so we keep the final 1/3% of the interval instead, leaving a range from approximatley 0.44 to 0.67.

Slides 8–9

We then repeat this process for the second D. We split the remaining interval again and retain D's section. We leave an interval from approximatley 0.44 to 0.59. The entire message of "DAD" has been encoded now.

Slide 10

Finally, we choose a number inside this interval. We choose 0.5, which can be represented in binary as 0.1, or simply as 1 in this context. The decoder can use this value and the same symbol probabillities to reconstruct the original message.
