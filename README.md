# ECM3428

## Running
Follow these instructions to run the program. (Will be updated as we progress)
1) Start in project root: `cd  ECM34281`
2) Create a venv: `python -m venv .venv`
3) Start the venv: `./.venv/Scripts/activate.ps1`
4) Upgrade pip: `python.exe -m pip install --upgrade pip`
5) Install requirements: `pip install -r requirements.txt`
6) Run the program: `python src/main.py`
7) exit the venv: `deactivate`
